# Tower Wizard - Multi Translation Mod

Welcome to multi language translation mod for **Tower Wizard**! This tool allows you to easily play the game in: Brazilian Portuguese (PT-BR), Spanish (ESP) or Japanese (JP).

## 📦 Requirements
* The base game **Tower Wizard**.

## 📥 How to Install Steam
1. Go to the [Releases](../../releases) page on the right side of this GitHub repository.
2. Download the latest `TowerWizard_Translation_vX.X.zip` file.
3. Open your Steam library, right-click on **Tower Wizard** -> **Manage** -> **Browse local files**.
4. Extract all files from the `.zip` directly into this main game folder (where the `Tower Wizard.pck` file is located).
5. Double-click the `translation.bat` file.
6. Choose your desired language from the menu. The tool will automatically create a backup of your original game!
7. Launch the game through Steam and enjoy!

## ⚙️ Troubleshooting & Uninstallation
* **False Positive (Antivirus):** Because this mod uses a `.bat` file and an `.exe` (`gdtr-tools.exe`) to modify the game's `.pck` file, your antivirus or Windows Defender might flag it. This is normal. You can safely add an exception for the game folder.
* **How to Uninstall:** Open `translation.bat` and select Option 4 (`Restore Original Backup`). Alternatively, delete `Tower Wizard.pck` and rename `Tower Wizard_BACKUP.pck` to `Tower Wizard.pck`.
